# 바로링크(BaroLink) 개인정보처리방침

시행일: 2026년 11월 __일

이 방침은 크롬 확장 프로그램 "바로링크"(이하 확장 프로그램)에 적용됩니다.

## 1. 요약

확장 프로그램은 사용자의 정보를 수집해 외부로 보내지 않습니다. 서버, 회원가입, 광고, 분석 도구, 외부 AI를 사용하지 않으며, 모든 처리는 사용자의 브라우저 안에서만 이루어집니다. 단, 사용자가 웹 검색창에 입력해 검색한 검색어는 사용자가 크롬에 설정한 기본 검색엔진으로 전달됩니다.

## 2. 확장 프로그램이 읽는 정보

| 정보 | 쓰는 곳 |
| --- | --- |
| 크롬 북마크의 제목, 주소, 폴더 구조 | 새 탭에 북마크 표시, 분류, 검색 |
| 북마크를 저장한 시각, 크롬이 기록한 마지막 사용 시각 | 잊고 있던 북마크 고르기, 요즘 쓰는 북마크 보호 |
| 크롬이 저장해 둔 사이트 아이콘 | 북마크 아이콘 표시 (웹사이트에 접속하지 않음) |
| 자주 방문한 사이트 목록 (선택) | 사용자가 [고정하기]를 누르고 허락했을 때만, 고정할 북마크를 고르는 데 사용. 저장하지 않음 |

웹 검색창에 입력한 검색어는 사용자가 크롬에 설정한 기본 검색엔진으로만 전달되며, 확장 프로그램은 검색어를 저장하지 않습니다.

구글 계정의 이메일, 이름 같은 계정 정보는 읽지 않습니다. 내 정보 창은 북마크 동기화가 켜져 있는지와 북마크·폴더 개수, 마지막 정리 날짜만 보여 줍니다.

## 3. 확장 프로그램이 저장하는 정보

다음 정보를 크롬의 로컬 저장소(chrome.storage.local)에만 저장합니다. 이 정보는 사용자의 컴퓨터에만 남고, 다른 기기나 서버로 보내지 않습니다.

- 정리 기록: 되돌리기와 기록 화면을 위한 북마크별 원래 위치와 옮긴 폴더, 북마크 제목, 정리한 시각
- 사용자가 직접 옮긴 북마크의 ID와 옮긴 시각
- 새로 저장한 북마크의 ID, 새 북마크 정리에서 "그대로 두기"로 둔 북마크의 ID
- 확장 프로그램 화면에서 북마크를 연 시각
- 고정한 북마크, "이제 안 봐도 됨"을 누른 북마크, 첫 정리 카드 상태
- 정리하는 동안만 쓰는 표시: 옮기는 북마크의 ID, 목적지 폴더 ID, 시각 (1분이 지나면 쓰지 않음)
- 크롬이 북마크를 가져오는 중인지 나타내는 시각
- 새 탭 꾸미기 설정: 색상, 배경, 글꼴<!-- TODO: 11/23 글꼴이 빠지면 이 단어 삭제 -->, 고른 대체 이미지
- 사용자가 올린 프로필 사진과 배경 사진 (원본이 아니라 줄인 사진만)

## 4. 크롬 북마크를 바꾸는 경우

확장 프로그램은 사용자가 [정리하기], [되돌리기], 폴더 만들기·이름 바꾸기·삭제, 북마크 삭제, 폴더로 이동, 끌어서 옮기기(앱 순서 바꾸기, 폴더에 넣기)를 했을 때만 크롬 북마크를 바꿉니다. 설치만 해서는 북마크가 바뀌지 않습니다. 폴더를 삭제할 때도 안의 북마크는 지우지 않습니다.

## 5. 제3자 제공

사용자가 검색한 검색어가 기본 검색엔진으로 전달되는 것 말고는, 어떤 정보도 제3자에게 판매하거나 제공하지 않으며, 광고나 신용 평가에 사용하지 않습니다.

## 6. 보관과 삭제

확장 프로그램을 삭제하면 3번의 저장 정보도 크롬이 함께 지웁니다. 크롬 북마크와 정리로 만들어진 폴더는 사용자의 크롬에 그대로 남습니다. 북마크를 삭제하면 새 북마크 기록과 직접 옮긴 기록은 바로 지우고, 고정, "이제 안 봐도 됨", 연 시각, "그대로 두기" 정보는 다음에 새 탭을 열 때 지웁니다. 정리 기록은 기록 화면과 되돌리기에 쓰이므로 지우지 않으며, 삭제한 북마크의 제목과 이동 정보가 확장 프로그램을 삭제할 때까지 남을 수 있습니다.

내 정보 창의 [사진 지우기]를 누르면 올린 프로필 사진과 고른 대체 이미지를 함께 지우고 기본 그림으로 돌아갑니다. [배경 사진 지우기]를 누르면 올린 배경 사진을 지우고 기본 배경(구름)으로 돌아갑니다. 확장 프로그램을 삭제해도 올린 사진은 지워집니다. 꾸미기 설정도 확장 프로그램을 삭제할 때 함께 지워집니다.
